# The Future of AI Careers

A research hub exploring emerging careers in artificial intelligence, including role descriptions, responsibilities, skills, tools, education pathways, and career outlook.

## Website

https://guilberth19.github.io/ai-career-research/

## Built with

- VitePress
- GitHub Pages
- GitHub Actions

## Run locally

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
```
