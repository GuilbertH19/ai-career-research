<div class="role-hero">
  <div class="career-eyebrow">CAREER PROFILE <span>•</span> AUTONOMOUS SYSTEMS</div>
  <h1>AI Agent Engineer</h1>
  <p class="role-lede">Designs AI-powered systems that can use tools, retrieve information, and coordinate multi-step workflows with appropriate oversight.</p>
  <div class="career-intro-meta"><span>Agent workflows</span><span>API integration</span><span>Evaluation &amp; controls</span></div>
</div>

<div class="career-section-heading"><div><div class="career-eyebrow">THE ROLE</div><h2>Build systems that can take action</h2></div><p>Agent Engineers combine language models with tools, data, and safeguards to complete defined tasks.</p></div>
<div class="role-overview">
  <div><span class="role-label">PRIMARY FOCUS</span><strong>Design and evaluate AI agents</strong><p>Create workflows that allow models to plan steps, access approved tools, and return useful results.</p></div>
  <div><span class="role-label">TYPICAL COLLABORATORS</span><strong>Backend, product, and platform teams</strong><p>Coordinate system behavior, product requirements, and operational controls.</p></div>
</div>

<div class="career-section-heading"><div><div class="career-eyebrow">DAY-TO-DAY WORK</div><h2>What the work involves</h2></div><p>Agent systems require careful testing because their outputs and actions can vary.</p></div>
<div class="role-detail-grid">
  <div><span>01</span><strong>Design workflows</strong><p>Define how an agent receives tasks, chooses steps, and completes a workflow.</p></div>
  <div><span>02</span><strong>Connect tools and data</strong><p>Integrate language models with APIs, databases, and approved services.</p></div>
  <div><span>03</span><strong>Test reliability</strong><p>Evaluate task completion, error handling, and behavior in unusual situations.</p></div>
  <div><span>04</span><strong>Build oversight</strong><p>Include permissions, human review, and safeguards for consequential actions.</p></div>
</div>

<div class="career-section-heading"><div><div class="career-eyebrow">CAPABILITIES</div><h2>Skills that matter</h2></div><p>The role blends backend engineering with practical knowledge of language models and evaluation.</p></div>
<div class="role-skill-panels">
  <div><strong>Engineering foundation</strong><p>Python or TypeScript, backend development, APIs, databases, and software testing.</p></div>
  <div><strong>Agent development</strong><p>Prompt and context design, retrieval-augmented generation, tool use, and workflow orchestration.</p></div>
  <div><strong>Reliability and safety</strong><p>Evaluation, monitoring, access controls, security fundamentals, and human oversight.</p></div>
</div>

<div class="career-section-heading"><div><div class="career-eyebrow">TOOLS &amp; TECHNOLOGY</div><h2>A typical toolkit</h2></div><p>Tools change quickly in this emerging field; focus on concepts that transfer between platforms.</p></div>
<div class="role-tool-row"><span>Model APIs</span><span>Python</span><span>TypeScript</span><span>Orchestration frameworks</span><span>Vector databases</span><span>Observability</span><span>Cloud services</span></div>

<div class="career-section-heading"><div><div class="career-eyebrow">GETTING STARTED</div><h2>Build your pathway</h2></div><p>Start with software fundamentals before adding agent behavior and tool integrations.</p></div>
<div class="role-pathway">
  <div><span>01</span><strong>Learn programming and APIs</strong><p>Build a small backend service and understand how applications exchange data.</p></div>
  <div><span>02</span><strong>Create a bounded agent project</strong><p>Build an assistant that retrieves trusted information and uses a limited set of tools.</p></div>
  <div><span>03</span><strong>Evaluate and document</strong><p>Test success rates, failure cases, permissions, and when a human should review an action.</p></div>
</div>

<div class="career-research-note"><div class="career-note-mark">i</div><div><strong>Research note</strong><p>Agent Engineer is an evolving title. Compare employer descriptions and investigate how each organization defines autonomy, evaluation, and human approval.</p></div></div>
