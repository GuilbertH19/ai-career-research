# AI Agent Engineer

## Role overview

An AI Agent Engineer builds software systems that use AI models to plan tasks, use tools, retrieve information, and complete multi-step workflows with appropriate controls.

## Common responsibilities

- Design agent workflows and tool integrations.
- Connect language models to APIs, databases, and internal systems.
- Test task completion, reliability, and failure handling.
- Add human review and safeguards for important actions.
- Monitor performance and improve workflows.

## Useful skills

- Python or TypeScript.
- API integration and backend development.
- Prompt and context design.
- Retrieval-augmented generation (RAG).
- Evaluation, testing, and security fundamentals.

## Common tools

Model APIs, orchestration frameworks, vector databases, observability tools, and cloud services may be used.

## Learning pathway

Start with programming and API development. Build a small assistant that retrieves information from trusted sources, uses a limited set of tools, and clearly asks for human approval before consequential actions.
