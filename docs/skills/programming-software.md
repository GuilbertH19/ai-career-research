<div class="career-section-heading"><div><div class="career-eyebrow">WHY IT MATTERS</div><h2>Where this skill fits</h2></div><p>How this capability contributes to effective, responsible AI work.</p></div>
<div class="skill-detail-panel"><p>Programming turns ideas into working systems. AI teams use software engineering to connect models with products, build reliable services, and maintain systems after launch.</p></div>

<div class="career-section-heading"><div><div class="career-eyebrow">CORE KNOWLEDGE</div><h2>What to learn</h2></div><p>These concepts form a useful starting point. The depth required depends on the role.</p></div>
<div class="skill-concept-grid"><div><span>01</span><strong>Python and TypeScript</strong></div><div><span>02</span><strong>APIs</strong></div><div><span>03</span><strong>Git and version control</strong></div><div><span>04</span><strong>Data structures</strong></div><div><span>05</span><strong>Testing and debugging</strong></div><div><span>06</span><strong>Software design</strong></div></div>

<div class="career-section-heading"><div><div class="career-eyebrow">PRACTICAL APPLICATION</div><h2>Put it into practice</h2></div><p>A focused project helps demonstrate understanding more clearly than a list of technologies.</p></div>
<div class="skill-detail-panel skill-project"><div class="career-eyebrow">SUGGESTED PORTFOLIO PROJECT</div><p>Build a small application that calls an AI model through an API. Add error handling, automated tests, and a short explanation of how the application works.</p></div>

<div class="career-section-heading"><div><div class="career-eyebrow">LEARNING PATH</div><h2>How to develop this skill</h2></div><p>Build knowledge progressively and reinforce it through small, well-documented projects.</p></div>
<div class="skill-detail-panel"><p>Start with one programming language. Learn variables, functions, data structures, and debugging. Then practice APIs, version control, testing, and building complete small applications.</p></div>
