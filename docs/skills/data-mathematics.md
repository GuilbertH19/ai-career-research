<div class="career-section-heading"><div><div class="career-eyebrow">WHY IT MATTERS</div><h2>Where this skill fits</h2></div><p>How this capability contributes to effective, responsible AI work.</p></div>
<div class="skill-detail-panel"><p>AI systems depend on data that is relevant, accurate, and responsibly handled. Mathematical foundations help practitioners understand patterns, uncertainty, and model performance.</p></div>

<div class="career-section-heading"><div><div class="career-eyebrow">CORE KNOWLEDGE</div><h2>What to learn</h2></div><p>These concepts form a useful starting point. The depth required depends on the role.</p></div>

<div class="career-section-heading"><div><div class="career-eyebrow">PRACTICAL APPLICATION</div><h2>Put it into practice</h2></div><p>A focused project helps demonstrate understanding more clearly than a list of technologies.</p></div>
<div class="skill-detail-panel skill-project"><div class="career-eyebrow">SUGGESTED PORTFOLIO PROJECT</div><p>Analyze a public dataset. Clean missing or inconsistent values, write SQL queries to answer a question, and explain what the data can and cannot tell you.</p></div>

<div class="career-section-heading"><div><div class="career-eyebrow">LEARNING PATH</div><h2>How to develop this skill</h2></div><p>Build knowledge progressively and reinforce it through small, well-documented projects.</p></div>
<div class="skill-detail-panel"><p>Learn basic statistics and probability, practice SQL and data cleaning, then study linear algebra and calculus as needed for your chosen specialization.</p></div>
